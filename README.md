# wallpaper-changer-service

> Сервис смены обоев для Hyprland. Для любимых Linux-юзеров 🐧

Демон, который следит за горячими клавишами и меняет обои на нескольких мониторах.  
Сервер + клиент + логирование через `systemd --user`.

---

## 🚀 Старт

Добавь автозапуск в конфиг Hyprland:

```ini
exec-once = ~/.config/hypr/wallpaper_autostart.sh
```

---

## ⌨️ Бинды для взаимодействия

Добавь в конфиг Hyprland:

```ini
bind = $mainMod, W, exec, /home/admin/.config/hypr/wallpaper_client.sh change
bind = $mainMod, L, exec, /home/admin/.config/hypr/wallpaper_client.sh toggle_auto
```

- `$mainMod + W` — сменить обои вручную.
- `$mainMod + L` — включить/выключить автоматическую смену.

---

## 📁 Пути

Путь к папке с обоями. При желании можешь поменять:

```bash
WALLPAPER_DIR="/home/admin/Pictures/wallpaper"
```

> ⚠️ Убедись, что путь существует и в нём есть изображения.  
> Файлы, не подходящие по шаблону имени, переименовываются автоматически.

---

## 🧩 Как это работает

- **Сервер** — живёт в фоне, слушает сигналы, меняет обои, пишет логи.
- **Клиент** — тонкий скрипт, который отправляет сигнал серверу.
- **Логирование** — отдельный `systemd --user` сервис, пишет что произошло.
